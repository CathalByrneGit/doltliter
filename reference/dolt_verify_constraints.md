# Re-check constraints

Re-check constraints

## Usage

``` r
dolt_verify_constraints(con, tables = NULL, all = FALSE, output_only = FALSE)
```

## Arguments

- con:

  a \`DoltliteConnection\`.

- tables:

  optional table names; omit to check all.

- all:

  pass \`–all\`.

- output_only:

  pass \`–output-only\`.

## Value

The function's return value.
